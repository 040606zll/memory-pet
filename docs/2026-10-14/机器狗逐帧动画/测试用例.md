# 逐帧动画测试用例

日期：2026-10-15。自动化测试实际文件位于frontend/tests，素材检查与真实截图另存本目录。

| 场景 | 验证目标 | 方法 |
| --- | --- | --- |
| 全九动作预加载 | 全部解码后才能交互，运行时不重复取图 | dogSpriteAssets及RobotDog单测 |
| 错误、超时、取消 | 中文错误可重试，已解码和迟到资源释放 | loader及组件单测 |
| 真正逐帧 | 时间推进选择不同源rect，遵循sequence | player单测及实际sourceFrames |
| 比例与脚底 | 宽尾帧不改变整狗比例，锚点固定 | geometry单测及实际关键帧 |
| 动作交接 | 可见画布不先clear，完整离屏提交 | renderer单测及整画布alpha检测 |
| 尺寸变化 | 零尺寸保留，整数尺寸相同不resize | renderer单测 |
| 暂停/恢复 | 冻结帧保留，活动时间停，旧指令不重放 | clock/组件单测及手机帧号 |
| 主动与自主动作 | 三按钮、语言队列和无人操作动作 | 组件单测及实际浏览器 |
| 两模式 | 训练/正式保留，真实模型和引用正常 | 桌面真实会话及手机切换 |
| 响应式 | 手机布局完整，无横向溢出，输入可到达 | 390×844实际DOM及截图 |
| 构建 | 主App不带旧网格播放器，Sites产物可用 | build和test:sites |

执行：`pnpm run test:coverage`、`pnpm run build`、`pnpm run test:sites`，工作目录frontend。浏览器验收页为`/tests/dog-sprites-visual.html`。单测mock仅验证代码机制，不作为实际素材姿态或模型联网效果的证据。
