# 熊猫宠物前端使用说明

## 连接和使用

前端默认访问同源 `/api`，本地 Vite 将其代理到 `http://127.0.0.1:8797`；开发端口为 `8796`。

1. 点击「连接服务」，填写当前 MemoryOS 地址、API Key、用户 ID 和大模型 API 地址、模型、API Key。
2. 后端验证记忆服务与大模型成功后，界面显示已连接。现有配置的密钥可留空保留；不会把密钥写入浏览器存储。
3. 「训练」通过聊天生成候选。可修改、拒绝或确认；只有成功确认的内容会成为 MemoryOS 的长期记忆。
4. 「正式对话」使用服务返回的记忆回复。每条引用标明对应记忆内容，支持查看和搜索已确认记忆。
5. 输入中 Enter 发送，Shift+Enter 换行；发送时可取消，失败可重试，保留同一请求编号避免重复。
6. 页面右上菜单可查看历史、开启新会话、暂停宠物动作、切换语音朗读或查看明确标记的原型预览。

## 熊猫动作

熊猫在无人操作时会自己眨眼、点头、玩耍或伸懒腰。说「挥挥手」「眨眨眼」「伸个懒腰」等肯定动作指令时，后端生成对应动作，前端按帧执行。多个动作排队播放；显式指令优先于回复情绪和闲置动作。浏览器的减少动态偏好和手动暂停会停止动画。

头像、房间、高精静态熊猫与逐帧动作素材均来自独立资产，未把整张原型截图当作可操作页面。素材精确位置及动作帧记录在 `/assets/panda-animation.json`。

## 开发验证

- 安装：`pnpm install`。
- 本地：`pnpm dev`。
- 自动化：`pnpm test:coverage`。
- 生产构建：`pnpm build`。

前端按原稿的 1536×1024 视口还原桌面双栏，并提供窄屏纵向房间与聊天布局。视觉最终结论以 `design-qa.md` 和浏览器截图为准。
