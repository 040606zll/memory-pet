# 后端测试用例

传输层 HTTP 替身仅用于自动化，使用当前 MemoryOS `/recall`、`/ingest`、`/memories` 的真实返回形状和兼容模型的 choices/message/content 结构。运行中的产品无假数据、假模型或本地长期记忆兜底。

1. 连接表单：真实 MemoryOS readiness+用户作用域验证与模型问候；Key 不回传；失败保持旧连接。
2. 训练完整链：聊天生成候选→编辑事实→确认远端写入→重放确认不重复写入→历史候选状态同步。
3. 正式对话完整链：新会话召回已确认的训练记忆→模型 prompt包含真实事实→回复展示来源；正式模式候选强制为空。
4. 同号同内容幂等；同号不同消息/不同模式拒绝；不同会话同号具有独立远端 recall 请求编号。
5. 候选拒绝；已拒绝/已确认禁止编辑；不存在候选；空修正非法。
6. 上游鉴权失败、服务错误、模型结构无效、网络超时：中文错误不含堆栈；不持久化伪回复；同键可重试。
7. MemoryOS 跳过、冲突、澄清或零有效记忆不能被标记成功。
8. 会话、消息、记忆分页总数；按模式与文本查询；跨用户不读取历史。
9. Key 正常轮换保留历史；未验证的 Key 不能读取历史。
10. 动作命令顺序、否定命令、历史动作叙述、无命令时的情绪动作和中性空动作。
11. 服务地址禁止凭据、query、fragment及非HTTP；跨站origin、Host与Sec-Fetch-Site拒绝。
12. LLM挂起期间另一真实SQLite连接可写；取消不保存半条聊天且幂等状态可重试；断开监测取消协程。
13. 异常远端数据结构与未就绪状态不能误报连接成功。

覆盖率衡量实际业务源码 pet/；真实模型与真实MemoryOS联调、浏览器还原程度由master记录总测试报告，不以mock测试替代。
