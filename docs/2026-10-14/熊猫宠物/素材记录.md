## 动作验收

核心素材为 4 列 × 4 行，行序为 idle、blink、wave、stretch；扩展素材行序为 nod、shake_head、happy、sleep。

- idle：同一坐姿，轻微头部移动/呼吸和眨眼；第 1 帧爪靠脸，与训练原稿一致。
- blink：睁眼 → 半闭 → 完全闭眼 → 睁眼，眼部真实变形。
- wave：胸前 → 脸旁 → 头顶 → 向外摆爪，为真实关节姿势帧。
- stretch：双爪胸前 → 双爪侧举 → 双爪举高 → 双爪伸展，为真实关节姿势帧。
- nod：正视 → 低头 → 进一步低头闭眼 → 抬头。
- shake_head：正视 → 向左转头 → 向右转头 → 正视，鼻子及耳朵方向改变。
- happy：普通表情 → 单爪抬起微笑 → 双爪抬起微笑 → 胸前合爪。
- sleep：半闭眼 → 闭眼靠爪 → 闭眼 → 闭眼靠另一爪；可循环作打盹。不是躺下睡觉动作。
- 未生成独立 sad、ear_twitch、walk、run、jump 动画素材，不应将已有动作替换命名后声称真实覆盖。
- 最终是否做到页面 100% 还原，仍须主流程在同一视口、同一状态对照浏览器截图验证；单独素材不能证明页面还原率。
