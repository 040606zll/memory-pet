# 机器狗后端说明与测试报告

## 修改与接口

`backend/pet/providers.py` 仅宠物分支人格改为毛绒机器狗，描述柔软毛绒外壳、机械眼睛和小狗陪伴感。新增 `wag_tail=摇尾巴`，`wave` 对应前爪挥动，兼容原挥手指令；允许模型根据情绪主动选择已实现动作。普通 `surface=memory` 提示词原样保留。

`backend/pet/schemas.py` 的 `ActionName` 和 `ACTIONS` 加入 `wag_tail`，旧七动作仍有效，不支持的模型动作仍被白名单过滤。

`backend/pet/actions.py` 新增摇尾巴、摇摇尾巴、摇一下尾巴、摇一摇尾巴、摇尾、摆尾等别名与 2200 毫秒持续时间。新增前爪挥动别名，输出沿用 wave。否定仍优先禁止同名动作；解析增加过去/引用动作集合，阻止模型将纯过去叙述重新解释为情绪动作。同条消息有新的明确请求时，该动作可以执行。原 commands 双返回值契约保持。

聊天返回动作结构仍为 `{"name":"wag_tail","trigger":"explicit或emotion","duration_ms":2200}`。前端需提供同名真实动画，后端不生成动画帧；本报告不代替前端视觉或真实模型验收。接口、数据库、长期记忆来源与确认 source_id 兼容现有记录。

训练只生成待确认候选，确认仍调用 MemoryOS HTTP 写入；正式对话 candidates 强制为空，召回来源仍是 MemoryOS，普通页 actions 强制为空。没有修改 MemoryOS 核心、凭据、环境、认证或召回逻辑。
