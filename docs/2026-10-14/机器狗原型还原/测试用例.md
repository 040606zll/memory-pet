# 机器狗测试用例

| 用例 | 方法与预期 |
| --- | --- |
| 原图角色 | 附件及reference SHA256一致；实际GPU与源裁切同500×544并排检查脸、LED眼、鼻、舌、胸牌、耳、四爪和尾 |
| 八动作 | DogMotion与PetMachine受控时钟；真实GPU中段截图，姿态连续，时长匹配，回到闲置 |
| 自主动作 | 不操作仍呼吸、眨眼、动耳和轻摆尾 |
| 排队及打断 | 同一canvas/纹理，切换从当前pose平滑衔接 |
| 暂停 | 停止draw但保留最后画面，真实浏览器帧号不变 |
| 闲置闭眼恢复 | 调度到10730ms自然闭眼，暂停至22000ms，22016ms恢复；第一pose逐字段等于冻结pose |
| 旧指令 | 暂停/预览期间和重复actions不重新入队 |
| 尺寸 | 零尺寸保留原帧，同整数尺寸不resize，有效变化才resize |
| 资源错误 | 加载/重试/卸载/着色器错误有中文提示并释放资源 |
| 手机 | 实际375×844训练和正式两模式、三按钮；眼/耳/尾/脚完整，无横向滚动，气泡和控件不遮挡 |
| 真实训练 | 浅蓝色偏好与摇尾；生成待确认候选，验收拒绝，不写入测试偏好 |
| 真实正式 | 询问身份并眨眼/摇尾；实际机器狗人格、动作和MemoryOS来源 |
| 后端兼容 | 新wag_tail、旧七动作、否定/过去保护；普通助手动作恒为空 |
| 连续帧 | 真实GPU探针与关键帧检查，采样blankFrames=0；范围限定在采样帧及角色中心 |
| 构建 | 生产build与4项包装测试，API不错误回退HTML |

组件和渲染器单测使用受控时钟与WebGL模拟，证明逻辑及生命周期；实际画面另用浏览器GPU和截图，不用mock代替视觉证据。
