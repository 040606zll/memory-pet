# 回归用例

复现条件：上游已 ready、用户及 Key 权限有效，但 profile=simple、development 或缺省；登录后读取状态或重试连接。修复前四条专用回归均失败并出现原提示。

| 场景 | 预期 |
| --- | --- |
| ready + simple/development/缺省 profile | 状态已连接，重试成功，可创建会话，不返回生产鉴权提示 |
| simple + 上游用户接口 401 | 重试返回 503 中文凭据错误，不能绕过鉴权 |
| production/simple 下两账号完整业务链路 | 各自写入、确认、跨会话召回，其他账号不能访问 |
| 上游 starting | 保留未就绪错误，不创建远端用户 |
| 重复连接及并发初始化 | 保留稳定映射及防重复创建行为 |

专用复现文件：`backend/tests/bug_fix/2026-10-15/本地记忆连接生产模式误拦截/test_profile_connection.py`。

从项目根目录运行：

```bash
/opt/anaconda3/envs/xyd/bin/python -B -m pytest tests/backend/test_accounts_auth.py tests/backend/test_connections.py backend/tests/bug_fix/2026-10-15/本地记忆连接生产模式误拦截/test_profile_connection.py -q
```

自动化使用临时数据库和 HTTP 替身，不创建真实 MemoryOS 用户。
