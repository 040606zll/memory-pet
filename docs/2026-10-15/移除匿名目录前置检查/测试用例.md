# 移除匿名目录前置检查测试用例

测试文件：tests/backend/bug_fix/2026-10-15/移除匿名目录前置检查/test_connection_without_probe.py；同步更新 tests/backend/test_connections.py 的原匿名目录拦截用例。

| 场景 | 预期 |
| --- | --- |
| 上游匿名目录可读，后端已有 Key 和用户 | 连接成功，客户端不再发匿名目录请求，使用服务端 Key 完成绑定 |
| 空目录、未配置用户 | 创建实际响应 UUID，后续重连复用，只建号一次 |
| 上游携带 Key 查询目录返回 401 | 语义化鉴权失败，不调用模型，不替换连接 |
| 上游缺失有效 api_key_id | 仍拒绝，不替换连接 |
| 目录与用户详情归属不一致 | 仍拒绝，原连接保留 |
| 训练、候选确认、新会话召回 | 取得记忆编号，独立会话召回对应记忆，全部目录请求带 Key |
| 原有唯一绑定、禁止换绑、并发、轮换、额度和失败恢复 | 既有回归继续通过 |

全部使用临时数据库、隔离配置及 HTTP 传输替身。没有对真实用户执行创建或写记忆，不读取实际模型 Key。替身返回有效归属信息只验证宠物代码行为，不证明未开启鉴权的 MemoryOS 已实现用户隔离。
