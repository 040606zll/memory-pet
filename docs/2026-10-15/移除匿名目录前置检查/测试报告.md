# 移除匿名目录前置检查测试报告

日期：2026-10-15。环境：macOS、Conda xyd、Python 3.11.15。

## 修改范围与原因

- backend/pet/connections.py：删除连接流程中的匿名目录隔离探测调用，增加中文注释说明后续归属验证仍保留。
- backend/pet/providers.py：删除不再使用的 check_directory_scope 方法及其匿名请求、409 阻断提示。
- tests/backend/test_connections.py：将原来的匿名可读阻断用例更新为不发匿名请求并继续连接。
- tests/backend/bug_fix/2026-10-15/移除匿名目录前置检查/test_connection_without_probe.py：新增六项接口链路回归，覆盖服务器 Key 复用、创建复用、实际鉴权失败、缺失归属、归属不一致及写入后跨会话召回。
- README.md、DEPLOY.md、既有 Key 用户绑定接口与用例文档：同步当前连接规则。
- 本目录 API接口文档.md、测试用例.md、测试报告.md：记录升级方法、边界与验证结果。

本次为用户明确要求删除的前置检查，不改变 MemoryOS 本身的鉴权或生产配置，不改前端、实际配置文件、凭据、用户数据和数据库结构。

## 修改前复现

运行新增回归脚本，模拟用户目录允许匿名读取。旧版 POST /api/connection 返回 409：MemoryOS 用户目录尚未启用鉴权，请管理员开启 AUTH_ENFORCED 后再自动绑定用户。测试期望携带已配置 Key 继续连接，修改前得到 1 failed，符合用户要求删除的阻断点。

## 风险与服务器验收

用户指定取消目录隔离预探测后，不再由宠物端识别上游全站目录是否按 Key 过滤。本地绑定只约束上游返回的 Key 标识和用户 UUID，不能在未鉴权目录中证明输入 Key 的身份。实际用户响应缺少有效 api_key_id 时，原有归属校验仍会拒绝。没有扩大本次范围或自动删除其他校验。

服务器更新两个 Python 文件并重启宠物后端后，使用原连接配置验证不再出现 AUTH_ENFORCED 预探测提示，随后验收真实用户绑定、训练确认和跨会话召回。无需重建前端或数据库迁移。本地通过不代表目标服务器已更新或其兼容模式响应一定满足归属字段契约。
