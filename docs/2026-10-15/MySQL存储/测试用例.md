# MySQL 存储测试用例

日期：2026-10-15。

## 不连接真实数据库的检查

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| S01 | 读取配置文件、同目录覆盖文件、环境变量 | 字段正确映射，环境优先，未输出真实密码 |
| S02 | 旧 SQLite 路径或非 MySQL URL | 拒绝作为运行时数据库，不回退 SQLite |
| S03 | 端口无效、库名无效、密码含特殊字符 | 无效配置中文错误；合法密码正确构造 URL |
| S04 | 检查 MySQL 全量 SQL | 9 张表、显式业务主键、utf8mb4、无物理外键 |
| S05 | 检查 URL 长度与索引 | URL 保留 2048 字符，摘要为 BINARY(32)，索引不直接包含完整 URL |
| S06 | 001 在 MySQL、SQLite、PostgreSQL 方言运行替身 | 选择对应 SQL；未知方言执行前报错 |
| S07 | 005 遇到空库或兼容的新表替身 | 使用同一全量基线，重复执行安全 |
| S08 | 005 遇到旧 URL 主键、生成摘要列或短 URL 列 | 明确要求全新空库，不执行破坏性变更 |
| S09 | 005 在历史 SQLite、PostgreSQL 链运行 | 不把旧库转换成 MySQL |
| S10 | 破坏性 downgrade | 拒绝执行，提示先备份并获得授权 |
| S11 | 模型或 MemoryOS 调用期间观察数据库连接 | 已退出短事务，事件循环不被同步数据库访问阻塞 |
| S12 | 请求取消与重试 | 短事务完成后再清理状态，不能产生迟到提交 |

## 专用 MySQL 集成验收

以下必须使用管理员明确授权的专用测试库，不能指向实际用户库或 MemoryOS 数据库。需先配置真实连接；清理测试数据只允许在确认过的测试库内执行。替身或 SQL 文本检查不能替代这些用例。

| 编号 | 场景 | 期望 |
| --- | --- | --- |
| M01 | 全新空库启动与重复启动 | 创建 9 张表，第二次无重复建表错误，旧 SQLite 文件不被访问 |
| M02 | 生产 Alembic 升至 head 后再次执行 | 单头 005，兼容完整基线，版本信息正确 |
| M03 | 注册、重复注册、正确及错误密码登录、退出、过期 Cookie、CSRF | 响应与账号隔离一致，密码和令牌不明文落库 |
| M04 | 两个账号初始化 MemoryOS 用户 | 映射各自独立，重试复用，唯一键禁止共享远端用户 |
| M05 | 训练消息生成候选、编辑、拒绝、确认、同请求重放 | 消息正确持久化，仅确认写入长期记忆，重复请求不重复写入 |
| M06 | 正式对话和普通页面召回 | 调用真实接口，页面、模式和账号历史互不串用 |
| M07 | 中文、emoji、大小写不同的标识符 | 文本完整，业务标识符比较保持二进制语义 |
| M08 | 同一请求跨两个数据库连接并发执行 | 一次进入处理，其余重放或冲突，不重复调用上游 |
| M09 | 限流和绑定租约的并发数据库访问 | 短事务、锁顺序稳定，不出现丢失更新或重复绑定 |
| M10 | MySQL 断连、认证失败、权限不足 | 中文错误，无密钥或原始连接串泄漏，不创建 SQLite 回退库 |
| M11 | 单 worker 重启后登录、历史、映射复用 | 数据保留，中断操作可安全重试 |
| M12 | MySQL 备份后恢复到独立恢复库 | 表、账号和消息完整；MemoryOS 仍单独备份 |

当前并未完成多 worker 或多副本验收，不能以 M08 单独通过推导支持多进程部署。
