# 服务停止与重启测试报告

日期：2026-10-15。环境：macOS、Python 3.11.15、Conda xyd；Shell 联调使用临时 Conda 替身与环境名 memory，未切换开发服务环境。

## 根因与修复

旧 Shell 分支只接受 start/run，Python 入口也只执行 start，虽然已保存 backend.pid，但没有停止、状态和重启实现。修改前运行新增端到端用例，start 成功后 status 返回退出码 2 和用法文本，准确复现缺失能力。

新增 stop/restart/status 分支、进程身份记录、Unix 非阻塞管理锁、正常停止等待与失败保护。保留数字 PID 兼容性，并在停止前核验当前 Python 和实际 run.py。重启只有停止成功才启动；停止超时保留记录，不强制杀进程。Linux 优先用 pidfd，将信号绑定进程实例；不支持的内核仅在 ENOSYS 时回退，权限失败不会绕过。

## 影响与后续验收

所有真实进程和端口均位于临时目录、随机端口，应用使用临时数据库，不请求真实上游。未读取或修改开发者应用配置、密钥和当前服务运行记录；未安装依赖、修改数据库表或提交 Git。

仅更新启动管理代码、对应测试与文档，不改前端产物或业务接口。用户服务器尚未上传、停止、重启或重载。部署时同时更新两个启动文件，保留原有 Conda 路径和 memory 环境名；不要变更运行目录。按 API接口文档.md 验收停止后端口释放、未运行返回 3、重启后 PID 改变及健康成功。重启中断在途请求，页面填写的 MemoryOS Key 需重填并重新验证。
