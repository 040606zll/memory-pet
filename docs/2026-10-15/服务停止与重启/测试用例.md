# 服务停止与重启测试用例

测试目录：tests/backend/bug_fix/2026-10-15/服务停止与重启；补充 tests/backend/test_start_script.py 与 独立后端启动路径/test_backend_startup.py。

| 场景 | 预期 |
| --- | --- |
| 旧版执行 status | 返回用法错误和 2，作为修改前复现 |
| 含空格的 backend/backend 独立部署 | 全部管理命令定位同目录入口和指定 Conda 环境 |
| start → status → stop → status → stop | 健康成功；运行 0；停止 0；未运行 3；重复停止 0 |
| 实际宠物应用停止、重启 | 日志完成应用关闭；新 PID 健康成功；原进程退出 |
| restart 时服务未启动 | 正常启动且健康成功 |
| 重复 start | 拒绝，不修改原 PID，不创建第二实例 |
| PID 指向测试其他进程 | start/stop/restart/status 拒绝，不发送信号、不覆盖 |
| PID 为空、非数字、0、1、负数、超大或多行 | 拒绝，保留文件，不检查或停止无效 PID |
| 旧 PID 已退出 | status 为 3，stop 清理失效记录 |
| 旧版只有数字 PID | 核验当前项目命令后正常停止 |
| Linux 旧版相对 run.py | 必须同时核对真实工作目录 |
| 新版启动时间不一致、记录损坏 | 拒绝，保留记录及原进程 |
| PID 文件缺失但端口已占用 | 所有管理命令拒绝接管 |
| 并发管理命令 | 管理锁立即拒绝第二个命令 |
| SIGTERM 被忽略 | 停止超时报错，保留 PID，restart 不启动第二实例 |
| Linux /proc 绝对或相对入口 | 核验 Python、脚本、工作目录与启动时钟 |
| Linux 僵尸、进程消失或身份不完整 | 已退出视为停止；身份不完整拒绝 |
| pidfd 身份变化、正常信号、关闭描述符 | 身份变化不发信号；正常发送 SIGTERM；总是关闭描述符 |
| pidfd 内核不支持、权限失败、进程消失 | 仅 ENOSYS 回退；权限失败拒绝；消失不误杀 |
| ps 失败、其他进程、僵尸或已退出 | 安全拒绝或正确判断已停止 |
| 应用导入失败、健康超时、启动身份无法验证 | 只清理新子进程，不报告成功 |
| CLI 非法参数与系统异常 | 非法参数拒绝；系统错误中文提示，不输出内部错误 |

所有进程、端口和运行记录均隔离在临时目录；应用测试使用临时 SQLite，不读取开发者模型配置，不请求真实模型或 MemoryOS。Linux /proc 与 pidfd 路径使用模拟文件和信号替身验证；Linux 相对入口的真实进程测试在 macOS 跳过，不将模拟结果称作服务器验收。
