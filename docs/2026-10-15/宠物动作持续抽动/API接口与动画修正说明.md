# 宠物持续抽动修正说明

日期：2026-10-15。本轮只修复宠物动画，记忆业务、页面布局、认证、依赖与构建配置均未修改，没有新增后端API。

## 根因及修正

1. 没有任何操作时，spriteFrame仍按时间循环16张全身待机图，每1.6秒重来一次。生成图中头部轮廓、毛纹和脚的位置也有变化，因此不是平缓呼吸，而是整只宠物持续切换外观。现在闲置保持同一张中立姿态。
2. 共享PetMachine的随机自主列表包括点头和伸懒腰，停顿仅2–6.5秒。机器狗新增DogBehavior专用调度：首次等待5.5–9秒，动作结束后等待6.5–11秒，自主活动只眨眼，每第四次偶尔摇尾；点头、伸展等由用户/回复触发。共享PetMachine保持原样，不影响其他角色。
3. 即使某动作只移动眼睛或尾巴，原来整张生成帧切换仍会带动不该改变的身体像素。新增DogFramePainter：固定同一中立图，只在活动部位播放真实源图片帧，静止区域保持原图。相邻源帧在活动区域做加权混合，使用柔边遮罩和固定等比比例；没有网格、骨骼、局部像素拉伸或新增图片生成。
4. 不同图集的起止中立外观不同。所有动作起手收势共用blink首帧的中立图，并逐渐进入/退出活动区，动作交接继续保留完整上一帧。

局部范围：blink为眼睛，wag_tail为尾巴（保护头部），wave为前爪，happy/nod/shake_head为头部。stretch/sleep仍为完整身体姿态，只显式触发。源帧来自既有图集，不改动素材文件。没有用整只角色浮动或缩放冒充呼吸。

## 文件与影响边界

- src/dogBehavior.js：机器狗专用调度，继承已有优先级/队列；其他角色的PetMachine未修改。
- src/dogSpriteComposition.js：静止中立图、局部柔边遮罩、真实源帧混合、统一比例与资源释放。
- src/dogSpritePlayer.js：安静姿态、统一中立帧、相邻帧选择、源帧/绘制帧分别计数，接入局部合成。
- src/RobotDog.jsx：接入专用调度，安静时标签“正在陪着你”，暂停时“安静陪着你”。三按钮和语言动作接口保留。
- tests/dogContinuity.test.js、dogBehavior.test.js、dogSpriteComposition.test.js：新的抽动回归；更新dogSpritePlayer和robotDog测试，不能再把无人操作时帧不断变化作为正确行为。
- tests/dog-continuity-visual.html：真实Canvas2D像素及节奏验收。旧dog-sprites-visual.html保持历史用途，主页面的新行为以本验收页为准。

以上路径均相对frontend。README、frontend/AGENTS.md和design-qa.md更新最新限制及验收，旧说明仍保留历史。

## 诊断精度与限制

安静脚部ROI与中立帧比较，同时确认该区域存在2894个不透明像素，防止空白与空白比较的假通过。实际186个姿态采样的静止区差异为0；活动部位有变化，避免把整个宠物冻结冒充修复。

调查时不同Canvas后端对半透明边缘读回有差异：alpha=1的白RGB与alpha=0黑RGB可产生255的原始RGB差异，肉眼贡献仅约1/255。验收使用预乘RGBA，并在diagnose=true时为画布统一willReadFrequently读回方式；生产URL默认不启用像素读回。没有通过放宽阈值隐藏真实位移。

这次主要解决持续抽动与不运动部位的跳变。生成素材在运动部位仍存在纹理和形态差异，完整身体大动作仍受素材质量限制；不宣称每个动作已达到真实动物或视频级连续性。资源仍需预加载，原图集约19MB/解码约57MB，另加复用合成画布。
