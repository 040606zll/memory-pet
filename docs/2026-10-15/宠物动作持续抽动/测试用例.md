# 测试用例

日期：2026-10-15。

| 用例 | 断言及结果来源 |
| --- | --- |
| 安静状态 | 用真实manifest采样200次，源姿态只有1个；旧实现为16个，回归先失败后通过 |
| 自主大动作 | 固定随机数0.7采样30秒，不能自动点头/伸展；旧实现伸展4次，回归先失败后通过 |
| 自主小动作 | 前三次眨眼、第四次摇尾，初始和动作后具有完整停顿 |
| 主动优先级 | 挥爪、点头顺序保留，主动动作可打断自主小动作 |
| 暂停恢复 | 暂停清队列，恢复有完整停顿，不追赶旧动作；真实页面冻结帧保持 |
| 统一中立帧 | 所有动作起手/收势activeWeight=0，共享同一图像与源矩形 |
| 真正局部图片帧 | 中段有nextFrame及frameMix，源帧键与合成绘制键分开 |
| 固定比例 | 宽高同一个比例，脚底稳定，不按每帧高度拉长压扁角色 |
| 局部合成 | 固定图→真实源帧→柔边遮罩；尾部保护头部，全身动作有兜底 |
| 资源/异常 | Canvas不可用中文错误、取消/重试/卸载释放，旧边界测试继续通过 |
| 实际静止像素 | 六种小动作各31个进度，共186样本，脚部ROI确有主体且差异0 |
| 动作确实可见 | 六种动作活动部位的画布像素变化不是0，实际关键帧视觉检查 |
| 布局/两模式 | 三按钮与训练/正式切换，输入、标题和卡片保留 |

回归命令：frontend目录执行`pnpm exec vitest run tests/dogContinuity.test.js tests/dogBehavior.test.js tests/dogSpriteComposition.test.js`。完整检查`pnpm run test:coverage`、`pnpm run build`、`pnpm run test:sites`。实际页面`/tests/dog-continuity-visual.html`使用真实生产播放器；模拟Canvas单测不代替视觉检查。
