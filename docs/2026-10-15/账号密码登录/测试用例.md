# 账号密码登录测试用例

| 场景 | 操作 | 预期 |
|---|---|---|
| 未登录 | 访问所有业务与身份接口 | 401；不访问上游 |
| 注册 | 输入合法账号密码 | 建立账号、签发 HttpOnly/SameSite Cookie 与 CSRF，数据库保存密码散列及会话令牌散列 |
| 参数校验 | 短密码、超长账号、非法用户名 | 422 中文响应 |
| 重复账号 | 使用大小写不同的相同账号注册 | 409，不新建账号 |
| 登录失败 | 不存在账号、错误密码、多次尝试 | 相同中文错误；达到限额后 429 |
| CSRF | 登录后缺少或伪造 CSRF 修改数据 | 403；不访问上游 |
| 退出及过期 | 退出、修改会话到期时间 | 原 Cookie 不再可用 |
| 重启 | 同一临时数据库重新创建应用 | 有效会话与账号映射保留 |
| 上游故障 | MemoryOS 401 或无配置时注册 | 注册登录可完成；状态返回可读连接错误，重试接口返回上游错误 |
| 部署模式 | 上游 ready，profile 为 production/simple/development 或缺省 | 模式名称不拦截连接，仍验证实际用户和权限 |
| 用户绑定 | 两个本地账号使用同一个服务 Key | 各有唯一 MemoryOS 用户，Key 标识可相同 |
| 创建丢响应 | 上游创建成功后返回超时，再次连接 | 按稳定账号标记复用，无重复用户 |
| 并发连接 | 同一账号并行连接 | 只创建一个远端用户 |
| 服务端凭据 | 页面传入旧 Key、用户 ID、地址或模型参数 | 422，不泄漏参数与凭据 |
| 全链路隔离 | A 写入确认记忆，B 召回及访问 A 全部接口 | B 不见 A 记忆、会话、候选；所有越权路径 404 |
| 回切账号 | B 写入后重新登录 A | A 仍只能召回自身记忆 |
| 旧数据 | 旧 scope 会话存在后注册 | 数据保留，新账号不可见 |
| 原有业务 | 宠物/普通对话训练、候选确认、幂等重放、分页、取消 | 登录后原功能保持，通过既有回归 |
| 查询次数 | 候选数从 1 增至 5 后重放 | SELECT 次数保持恒定 |
| 迁移 | 新库与重复 Alembic 升级 | 四张账号相关表存在，唯一约束有效 |

测试入口：`python -m pytest tests/backend`。测试使用临时数据库与 MockTransport，不调用真实服务。

实际验收：2026-10-15 在 Conda xyd / Python 3.11.15 上，后端全量 274 通过、1 个既有 Linux 专用用例在 macOS 跳过。总行覆盖率 91%，账号模块 92%、认证模块 98%、接口模块 98%。新登录安全用例未设置跳过。
