# 测试用例

复现文件：`tests/backend/test_start_script.py`。
真实启动及失败路径：`tests/backend/bug_fix/2026-10-15/独立后端启动路径/test_backend_startup.py`。

1. 构造带空格的 backend/backend 目录，不创建根目录 scripts。旧版默认启动及显式 start 均报找不到 scripts/start_backend.py，修复后应成功调用同目录启动器。
2. 使用临时配置、临时数据库及空闲端口，启动真实 FastAPI 应用；健康接口返回 200，日志及 PID 保存正确。
3. 重复启动被端口预检拒绝，原子进程继续运行。
4. run.py 启动退出时报中文错误，不记录失败进程 PID。
5. 子进程不提供健康接口时，启动超时并终止本次子进程。
6. 模拟子进程不响应 terminate，在等待超时后执行 kill。
7. 原 Conda 固定配置、无效参数、失败码及前台模式用例继续通过。

所有测试均不使用真实模型或 MemoryOS，不读取开发者配置，不停止本机 8797 的原服务。
