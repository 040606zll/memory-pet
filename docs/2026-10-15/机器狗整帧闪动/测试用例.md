# 测试用例

1. 打开/tests/dog-temporal-visual.html?coherent=1，等待complete=true。以默认Canvas后端、301×558实际尺寸逐RAF提交八动作，检查完整角色连续帧中的双脸重影、身体跳位、亮度与可见面积变化。
2. 脸部单姿态检查：输出必须与该时刻选定的单张完整图片一致；不透明脸部平均通道偏差小于0.5。此检查针对透明叠加重影，不代表动物自然度评分。
3. 每动作从同一物理中立帧出发并回到同一帧；图片宽高、锚点固定。30Hz头部每步位移小于0.6像素、转角小于0.015弧度。
4. 相同姿态共享图集，资源小于80MiB；多次release只关闭一次共享ImageBitmap。取消、解码失败及解码后取消不返回半套素材。
5. 主页面主动摸头、眨眼、摇尾有效，无操作时保持稀疏自主活动；连续点击可排队，不创建新的canvas或图片请求。
6. 暂停后帧编号不变，按钮禁用；恢复沿图片序列回中立，不重放旧队列，不用透明淡化。
7. 训练/正式对话可切换，输入框与文案对应，页面仍显示记忆已连接，无横向溢出。
8. pnpm run test:coverage、pnpm run build、pnpm run test:sites通过。

单元测试使用mock Canvas验证调用与资源生命周期；浏览器诊断验证实际像素。两者不能互相替代。
