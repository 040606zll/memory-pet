# LangChain 对话测试用例

自动测试文件：`tests/backend/test_model_agent.py`。实际执行 LangChain Agent 和 SDK，仅以 `httpx.MockTransport` 替换远端 HTTP，数据库相关编排以 Store 替身验证；不把替身结果作为真实上游验收。

| 场景 | 断言 |
| --- | --- |
| 训练/正式对话 × 宠物/普通页面 | Agent 入口被调用，HTTP 发出一次；候选、动作符合原契约 |
| 历史和召回数据 | 输入包含本会话历史、真实召回结果与用户消息 |
| 根地址、/v1、完整端点 | 仅拼接一次 Chat Completions 路径 |
| 模型参数 | 保留 JSON、max_tokens、温度；仅 DeepSeek 携带关闭思考参数 |
| 401/403/429/503 | 中文错误，无 Key/上游堆栈；无自动重试 |
| 超时与网络断开 | 分别返回 504、502 |
| 无效、空白、截断、多块内容或意外工具调用 | 返回 502，不伪造回复 |
| 兼容 Markdown JSON 围栏 | 仍解析有效正文 |
| 请求取消 | 传递到 HTTP 传输，不关闭共享客户端 |
| 训练→确认→正式对话 | 确认前无 ingest；确认后写入且能召回，正式对话无候选 |
| 模型失败 | 幂等操作恢复失败状态，不保存消息 |

运行：`python -B -m pytest tests/backend/test_model_agent.py -q --cov=pet.model_agent --cov-report=term-missing`。

部署后用专用测试账号验证登录、训练、确认记忆、正式对话、同一请求重试及取消；这会产生真实模型调用和测试记忆，应在专用环境执行。MySQL 凭据未提供时，数据库链路用例跳过，不算通过。
