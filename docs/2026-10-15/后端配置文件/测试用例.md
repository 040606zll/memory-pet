# 后端配置文件测试用例

日期：2026-10-15。自动化入口：`tests/backend/test_settings.py`。

| 场景 | 预期 |
| --- | --- |
| 文件配置完整 | 创建真实 FastAPI 应用，连接验证请求使用文件指定的模型地址和名称 |
| 本机覆盖部分字段 | 只覆盖模型 Key，模型地址、名称、MemoryOS 和数据库配置继续沿用默认文件 |
| 环境覆盖 | 环境值覆盖本机文件；显式空值也覆盖，不回退至旧密钥 |
| 文件缺失 | 原有纯环境变量部署保持可用 |
| 不同工作目录启动 | 文件内相对数据库路径仍落在配置目录指定位置 |
| 无副作用 | 加载不会修改文件或进程环境 |
| 错误配置 | 未闭合字符串、未知分组、错误分组类型、未知字段和非字符串值均返回语义化中文错误，不回显测试秘密 |
| 文件不可读 | 不静默使用缺省值，阻止启动并提示检查配置 |
| 状态公开 | 配置模型并验证后，状态只有模型 configured 标志，无模型地址、名称和密钥 |

实际服务检查只读取 `/api/health` 和 `/api/status`，不产生模型调用或长期记忆。部署验收可由管理员使用专属测试用户在配置后验证连接，注意已有环境变量优先级更高。
