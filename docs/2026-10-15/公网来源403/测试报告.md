# 测试报告

日期：2026-10-15。

## 复现与原因

原线上 `http://81.71.39.10/pet-api/health` 返回 HTTP 403 和“此服务仅允许本机访问”。后端原 LocalOnlyMiddleware 硬编码本机 Host 与 Origin；公网 Nginx 保留真实 Host 后被拦截，说明请求已成功到达后端。

修复前新增真实配置链路测试，运行后失败：原配置加载器不支持 server 分组，证明不能只在配置文件填入白名单。修复后默认本机限制仍保留，显式配置的公网 IP 与浏览器 Origin 才被允许。
