# MySQL 库名误拦截测试报告

日期：2026-10-15。

## 根因与修复

MySQL 配置校验把数据库名限定为英文字母、数字和下划线，导致用户已存在的横线或中文库名在启动导入应用时被误拒绝。修复按 MySQL 库名规则检查长度、非法字符和末尾空格，并继续通过驱动参数原样传递库名。

主机、用户名和库名分别返回语义明确的中文配置错误，不回显连接信息。本次没有表结构变更，因此不增加 Alembic 或 SQL 文件。
