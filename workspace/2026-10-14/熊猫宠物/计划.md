# 熊猫宠物完整开发计划

目标：独立项目，忠实还原熊猫训练/正式对话原型，Python 接入真实大模型与当前 MemoryOS；支持主动闲置动作和对话指定动作，启动并验证前后端完整链路。

目录：backend 独立 FastAPI 服务；frontend React/JavaScript（沿用 Product Design 启动模板）；tests 自动化；docs/2026-10-14/熊猫宠物 保存接口、用例、报告；本目录记录协作。

职责：master 负责架构、真实 MemoryOS/LLM 联调、服务启动和浏览器验收；backend worker 实现后端、测试及接口契约；frontend worker 按原型实现界面与动画状态机；asset worker 生成并验收房间、熊猫动作素材。

验收：两种状态的视觉对比；训练候选纠正、确认及幂等；跨模式/跨会话真实召回；中文错误与连接配置；显式动作/情绪动作/无人操作动作；取消/失败/空状态；单元覆盖率 >=80%；桌面与移动交互；真实 API 和浏览器无错误。

当前 MemoryOS 仓库先只读，若需要修改必须列出影响及回归方案。禁止修改现有密钥与环境文件、禁止提交 git。秘密只能留在服务端，不能输出到日志或文档。
