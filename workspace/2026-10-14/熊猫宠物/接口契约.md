# 熊猫宠物接口契约

前端同源 `/api`，后端监听 127.0.0.1:8797。成功 JSON 为 `{code:0,message:"成功",data:...}`，失败为 `{code:HTTP状态,message:中文原因,data:null}`。秘密仅后端内存，连接响应仅布尔 configured。

- `GET /api/status` -> `{memoryos:{base_url,user_id,configured},llm:{base_url,model,configured},actions:[...],connected:false}` 不调用远端；`POST /api/connection` body `{memoryos:{base_url,api_key?,user_id},llm:{base_url,api_key?,model}}` 更新配置并验证 MemoryOS `/health/ready` 与用户 `/memories`，调用最小真实 LLM 问候验证，不输出 key。仅同origin时空 key 保留旧 key；更换origin必须填写新key，否则422且无外部请求。
- `POST /api/sessions` body `{mode:"training"|"chat",title?:string}` -> `{id,mode,title,created_at}`；`GET /api/sessions?page=1&limit=20&mode=...` -> `{items,total,page,total_pages}`；`PATCH /api/sessions/{id}` body `{mode:"training"|"chat"}` 允许同一框切换模式。
- `GET /api/sessions/{id}/messages?page=1&limit=100` -> 分页，message `{id,role:"user"|"assistant",content,emotion,actions:[{name,trigger:"explicit"|"emotion",duration_ms}],memories:[{id,content,source}],candidates:[{id,content,status:"pending"|"confirmed"|"rejected",memory_ids}],created_at}`。
- `POST /api/sessions/{id}/chat` body `{content:string(1..4096),request_id:string,pet_name?:string(1..12 默认小忆)}` -> `{user_message,assistant_message}`，先真实 MemoryOS 召回，再 LLM JSON；训练模式产生待确认 candidates，正式模式不自动写记忆。相同 request_id+content 返回已存结果；不同内容、模式或宠物名称 409；服务失败可同键重试；取消时释放事务。
- `PATCH /api/sessions/{id}/candidates/{candidate_id}` body `{content?:string,status?:"rejected"}` -> candidate，只允许操作 pending；上次写入结果不确定时冻结编辑/拒绝，要求按原内容重试确认。
- `POST /api/sessions/{id}/memories/confirm` body `{candidate_id:string}` -> candidate（status confirmed, memory_ids）。每修订稳定 source_id 在真实 MemoryOS 保证重试幂等，抽取未成功/有冲突时保留 pending 并返回中文错误。
- `GET /api/sessions/{id}/memories?page=1&limit=20&q=...` -> `{items:[{id,content,source,status,created_at}],total,page,total_pages}`：真实 MemoryOS 清单，包含跨会话长期记忆；来源也在回复 memories 字段展示。

动作白名单 `blink,wave,nod,shake_head,stretch,happy,sleep`。显式肯定动作优先，否定动作禁用；否则模型按回复情绪选有限动作，闲置动作由前端定时状态机执行，无须模型或网络。训练候选不是长期记忆，确认才写入 MemoryOS。

所有会话按当前 MemoryOS URL+user_id 绑定；连接切换不会泄露上一用户的聊天。LLM timeout 90秒，MemoryOS 90秒，无隐式重试。
