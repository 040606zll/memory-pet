# MySQL 存储替换计划

用户已确认：整个 memory-pet 使用新 MySQL 数据库，不迁移旧 SQLite 数据；连接信息只写可配置项，由用户自行填写真实值。

主代理负责数据库连接、Store、Accounts、Connections、Auth 和 API/Service 异步调用边界；worker 负责完整 MySQL 建表与 Alembic，以及测试迁移。测试使用独立环境，禁止读取或操作实际服务数据库。保留旧 SQLite 文件和历史 SQL，不再作为运行时后端。

拟修改：backend/pet/{database,store,accounts,connections,auth,main,service,settings}.py，backend/requirements.txt，backend/config.toml 的 storage 段，配置示例、MySQL SQL 和生产迁移，相关测试和部署文档。真实模型和 MemoryOS 配置不变。

数据库网络访问位于工作线程，事务必须短小；网络模型和 MemoryOS 调用期间不持有数据库连接。完成后验证注册、登录、账号隔离、聊天和记忆确认相关链路，明确区分真实 MySQL 测试与替身测试。不迁移、不删除旧数据、不提交 Git。
