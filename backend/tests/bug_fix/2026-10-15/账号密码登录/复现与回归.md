# 账号归属错误复现与回归

旧流程通过页面传入 MemoryOS Key，按 Key 查找或创建上游用户。上游用户记录缺少有效 UUID 或 api_key_id 时，user_record 返回“记忆服务未返回有效的用户与 API Key 归属信息”；同一服务 Key 下有多个真实用户时，仅以 Key 推断当前产品账号也不可靠。

新流程使用本地账号密码登录，后端用固定服务凭据为账号创建专属上游用户。标记 MemoryPet:<本地账号ID> 用于创建响应丢失后的恢复；本地映射以账号及服务 URL 唯一绑定，并限制同一远端用户不能属于两个本地账号。旧连接信息和旧会话不自动认领。

自动化回归入口：tests/backend/test_accounts_auth.py、test_connections.py，以及既有 test_api.py 与 test_memory_surface.py。所有测试使用临时 SQLite、模拟 HTTP 传输，不读取或改写实际业务库、凭据，不调用真实模型。
